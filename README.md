# Verity — Fabric 1.21.1

Мод для Minecraft Java Edition 1.21.1 на Fabric.

## Что добавлено

- Круглая жёлтая 3D-сущность `Verity`: гладкий шар, глаза и рот построены геометрией (без фона и швов).
- Verity поворачивается лицом к ближайшему игроку.
- Закрытая картонная коробка со скотчем и стрелками (текстура `verity_box.png`).
- Коробка подпрыгивает примерно каждые 18 тиков, пока сущность не нажмут.
- ЛКМ или ПКМ по коробке выпускает Verity с анимацией: коробка трясётся, скотч рвётся, клапаны распахиваются, Verity выпрыгивает с вращением, приземляется на крышку, коробка исчезает в облаке, и Verity спрыгивает на землю.
- Verity неуязвима (убрать можно только `/kill`), не горит и не исчезает.
- Verity всегда смотрит на ближайшего игрока, включая наклон вверх/вниз.
- Verity ходит на маленьких ножках и следует за ближайшим игроком (держит дистанцию ~2,5 блока, ускоряется, если отстала, и телепортируется, если отстала больше чем на 28 блоков).
- Физика: удар отталкивает её (сильнее при беге), при падении она отскакивает как резиновый мячик и сплющивается при приземлении. Урона она не получает.
- ПКМ по Verity: взять в руку. ПКМ по блоку: поставить её туда. Выбросить её нельзя; если игрок умер или вышел, Verity остаётся на месте.
- После выпуска проигрывается `verity_greeting.ogg` с приветственной сценой.
- Во время речи рот меняется каждые 3 тика; состояние синхронизируется через DataTracker и меняется одновременно со звуком.
- GLB-меш Verity разделён на переднюю и заднюю половины, поэтому модель остаётся объёмной, а прозрачная жёлтая текстура лица анимирует рот без фона.
- Команда `/spawnverity` доступна операторам.

## Установка

1. Установить Fabric Loader для Minecraft 1.21.1 и Fabric API 0.116.1+1.21.1.
2. Собрать мод командой `gradlew.bat build` из папки проекта.
3. Скопировать `build/libs/verity-fabric-1.1.1.jar` в папку `.minecraft/mods`.
4. Запустить игру и выполнить `/spawnverity`.

## Сборка из исходников

Требуется JDK 21. Выполнить:

```bash
./gradlew build
```

Готовый файл будет в `build/libs/verity-fabric-1.1.1.jar`.

## GLB-файлы

В папке `models/` лежат дополнительные модели. В архиве оставлены исходники и эти GLB-файлы, чтобы не распространять устаревший JAR, собранный до исправления renderer:

- `verity.glb` — круглая жёлтая модель Verity;
- `box.glb` — открытая прямоугольная коробка;
- `verity_animated.glb` — модель Verity с циклической анимацией рта.

Игровой renderer использует подготовленный Java-меш из GLB, потому что Fabric не загружает GLB напрямую без отдельного загрузчика моделей.
